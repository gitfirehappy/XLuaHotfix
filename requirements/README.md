# Requirements Directory

Store requirement-specific artifacts here.

Recommended structure:
- `requirements/{id}/brief.md` - problem statement and background
- `requirements/{id}/plan.md` - approved high-level plan summary
- `requirements/{id}/plan/` - detailed executable plan files
- `requirements/{id}/plan/drafts/` - non-executable drafts, direction convergence, and idea capture
- `requirements/{id}/review/` - review-phase artifacts and review notes
- `requirements/{id}/progress.txt` - factual progress log
- `requirements/{id}/notes.md` - optional supporting notes

Use `requirements/INDEX.md` as the top-level navigation entry.
