# 对话系统

> **关联代码** \| `Assets/Dialogue/`

## 概述

基于 Lua 数据驱动的对话系统。对话内容以 Lua 模块形式存储（数组结构），由 `DialogueController` 解析并驱动 UI 渲染。支持普通对话、分支选项、条件跳转和自定义函数回调。

## 系统架构

```
Lua 对话文件 → DialogueController 解析 → 逐条执行
                                           ├─ Sign 路由（# 普通 / % 选项 / $ 条件）
                                           ├─ Func 回调（> 即时执行 / < 交互执行）
                                           └─ NextID 跳转 → 下一条
                                                    ↓
                                              UI 渲染层
```

`DialogueController` 负责：
- 加载并解析对话 Lua 模块
- 按 ID 索引跳转
- 管理 `>` 即时函数和 `<` 交互函数的执行时机
- 内建跳转循环保护（超过 100 次自动终止）

函数注册通过 `DialogueFuncRegistry` 实现，支持 Lua 侧的类型声明和自动参数推导。

---

## 快速开始

```lua
local DialogueController = require("DialogueController")
DialogueController.Start("Dialogue/TestDialogue")
```

---

## 对话文件结构

对话数据为 Lua 模块，返回数组，每条语句为一个 table：

```lua
return {
    {Sign="#", ID="0", Character="小明", PosAndOp="left", Content="你好！", NextID="1"},
    {Sign="%", ID="1", Character="", PosAndOp="", Content="选项A", NextID="2"},
    {Sign="%", ID="2", Character="", PosAndOp="", Content="选项B", NextID="3"},
    {Sign="#", ID="3", Character="小明", PosAndOp="hide", Content="再见！", NextID="END"},
}
```

---

## 字段说明

### Sign：语句类型

| 值 | 类型 | 行为 |
|------|------|------|
| `#` | 普通对话 | 显示文本，点击后跳转 NextID |
| `%` | 选项 | 显示选项列表，玩家选择后跳转 |
| `$` | 条件判断 | 执行 Func 中第一个 `>` 函数，返回值作为跳转 ID |
| 空 | 等同 `#` | 默认普通对话 |

### ID

每条语句的唯一标识。起始 ID 建议为 `0`。

### Character：说话人

- 单角色：`"小明"`
- 多角色（同时显示/操作多个）：用 `;` 分隔，如 `"小明;小红"` —— 第一个为说话人，其余为附加操作目标
- 旁白：留空
- 角色名前缀 `角色_` 可用于单角色匹配多个 CharacterConfig，UI 只显示角色名

### PosAndOp：位置与操作

多角色用 `;` 分隔，单角色多操作用 `&` 分隔：

```
"left&diff1;hide"  → 角色1 左侧显示+差分1，角色2 隐藏
```

**固定操作**：

| 操作 | 说明 |
|------|------|
| `show` | 显示角色 |
| `hide` | 隐藏角色 |
| `diffX` | 切换差分（X 为编号） |
| `left` / `right` / `center` | 预设位置 |

### Content：对话内容

- 支持 `\n` 换行
- 条件判断（`$`）时可留空

### NextID：跳转目标

| 格式 | 含义 |
|------|------|
| `"3"` | 跳转到 ID=3 |
| `"1;2;3"` | 多个跳转目标（配合 `%` 类型生成选项） |
| `"END"` | 结束对话 |

条件判断（`$`）不使用 NextID 字段，跳转目标由函数返回值决定。

### Func：回调函数

| 前缀 | 时机 | 说明 |
|------|------|------|
| `>函数名` | 语句出现时立即执行 | 条件判断、状态设置 |
| `<函数名` | 点击/选择后执行 | 对话切换、事件触发 |

多函数用 `;` 分隔：`>func1;<func2`

### Params：函数参数

- 同函数多参用 `&` 分隔：`"hello&123"`
- 不同函数用 `;` 分隔：`"params1;params2"`
- 表类型参数用引号包裹：`"{1, 2, 'a', true}"`、`"{hp=10, name='boss'}"`

## 函数注册

```lua
local MyFunctions = {}
local mt = {__index = require("DialogueFuncRegistry").IDialogueFuncProvider}
setmetatable(MyFunctions, mt)

MyFunctions.MyFunc = {
    name = "MyFunc",
    paramTypes = {"string", "number"},  -- 可选：修正自动类型推导
    func = function(str, num)
        -- 实现
    end
}

return MyFunctions
```

### 参数类型适配

`paramTypes` 用于修正自动推导的类型：

| 声明 | 效果 |
|------|------|
| `"string"` | 强制转为字符串 |
| `"number"` | 字符串转数字 |
| `"boolean"` | `"true"`/`"1"` → true，`"false"`/`"0"` → false |
| `"table"` | 保持原值 |

### 参数自动推导规则

| 输入 | 推导结果 |
|------|---------|
| `123` | number |
| `"hello"` | string（保留引号内内容） |
| `true` / `false` | boolean |
| `nil` | nil |
| `{1,2,3}` | table（数组） |
| `{a=1,b=2}` | table（字典） |

常见类型错误及修复：

| 问题 | 原因 | 修复 |
|------|------|------|
| `"123"` → 数字 123 | 自动推导为 number | `paramTypes = {"string"}` |
| 布尔值 → 字符串 | CSV 存储为文本 | `paramTypes = {"boolean"}` |
| 表解析失败 | CSV 逗号冲突 | 引号包裹 `"{a=1,b=2}"` |

## 执行生命周期

```
Refresh()
  → 执行当前语句所有 ">" 即时函数
  → 渲染 UI（角色位置、对话内容、选项）
  → 等待玩家交互
  → 点击/选择后执行 "<" 交互函数
  → 按 NextID 跳转到下一条
  → Refresh() 循环
```

**关键规则**：
- 条件判断（`$`）类型：仅第一个 `>` 函数的返回值作为跳转 ID
- 在 `<` 函数中调用 `DialogueController.Start()` 可安全切换到新对话

---

## 注意事项

- **跳转循环保护**：内建计数器，超过 100 次跳转自动终止并报错
- **函数名冲突**：后注册的同名函数覆盖先注册的，日志输出警告
- **ID 唯一性**：确保每条语句的 ID 不重复，否则跳转可能进入错误分支
- **CSV 兼容**：如果对话数据来源是 CSV 转换，注意逗号和引号的转义处理
