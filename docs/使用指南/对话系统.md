# 对话系统使用指南

## 快速开始

### 启动对话

```lua
local DialogueController = require("DialogueController")
DialogueController.Start("Dialogue/TestDialogue")  -- 传入对话文件路径（不含.lua）
```

### 对话文件结构

对话数据为 Lua 模块，返回数组格式：

```lua
return {
    {Sign="#", ID="0", Character="小明", PosAndOp="left", Content="你好！", NextID="1", Func="", Params=""},
    {Sign="%", ID="1", Character="", PosAndOp="", Content="选项A", NextID="2", Func="", Params=""},
    {Sign="%", ID="2", Character="", PosAndOp="", Content="选项B", NextID="3", Func="", Params=""},
    {Sign="#", ID="3", Character="小明", PosAndOp="hide", Content="再见！", NextID="END", Func="", Params=""},
}
```

## 语义定义

### Sign：标识符

| 符号 | 类型 | 说明 |
|------|------|------|
| `#` | 普通对话 | 默认类型，显示文本后点击继续 |
| `%` | 选项 | 显示选项列表，玩家选择后跳转 |
| `$` | 条件判断 | 执行函数返回跳转ID |
| 空 | 普通对话 | 默认为 `#` |

### ID：唯一标识

每条语句唯一标识，起始ID建议为 `0`，也支持其他起始ID。

### Character：说话人

- 需要同时出现或不同位置操作时用 `;` 隔开，只将第一个作为说话人
- 允许空值，表示旁白
- `角色_xxx` 可用于单角色匹配多 CharacterConfig，UI 只显示角色名称

**示例**：
- `小明;小红` → 说话人为小明，对小红有额外操作
- `p1&p2;p1;p2` → p1&p2 同时说话，对二者有操作
- `;p1;p2` → 无说话人（旁白），对二者有操作

### PosAndOp：位置与操作

- 多角色操作用 `;` 隔开
- 单个角色多操作用 `&` 隔开

**固定快捷操作**：
| 操作 | 说明 |
|------|------|
| `show` | 显示角色 |
| `hide` | 隐藏角色 |
| `diffX` | 切换角色图片差分，X为编号 |
| `left`/`right`/`center` | 预设位置 |

**示例**：`left&diff1;hide` → 角色1左侧显示+差分1，角色2隐藏

### Content：对话内容

- 允许空值（用于条件判断）
- 使用 `\n` 换行

### NextID：跳转目标

| 格式 | 说明 |
|------|------|
| 单个数字 | 跳转到指定ID |
| `1;2;3` | 多个ID，显示选项 |
| `END` | 结束对话 |

**条件判断**：`$` 类型无 NextID，通过函数返回值决定跳转。

### Func：执行函数

| 前缀 | 时机 | 说明 |
|------|------|------|
| `>函数名` | 语句出现时 | 即时执行 |
| `<函数名` | 点击/选择后 | 交互执行 |

多函数用 `;` 隔开，如 `>func1;<func2`

### Params：函数参数

- 单个函数多参数用 `&` 隔开
- 不同函数参数用 `;` 隔开

**表类型参数**（建议用引号包裹避免 CSV 解析问题）：
- 列表：`"{1, 2, 'a', true}"`
- 字典：`"{hp=10, name='boss'}"`
- 嵌套：`"{drop={1,2}, info={id=1}}"`

## 函数注册

### Lua 函数注册

```lua
local DemoDialogueFunctions = {}
local mt = {__index = require("DialogueFuncRegistry").IDialogueFuncProvider}
setmetatable(DemoDialogueFunctions, mt)

-- 定义函数
DemoDialogueFunctions.MyFunc = {
    name = "MyFunc",                          -- 函数名
    paramTypes = {"string", "number", "table"}, -- 可选：参数类型声明
    func = function(str, num, tbl)
        -- 函数实现
    end
}

return DemoDialogueFunctions
```

### 参数类型适配

`paramTypes` 用于修正自动推导的类型：

| 声明类型 | 推导修正 |
|----------|----------|
| `"string"` | 任意值转字符串 |
| `"number"` | 字符串转数字 |
| `"boolean"` | `"true"`/`"1"` → true，`"false"`/`"0"` → false |
| `"table"` | 保持原值 |

---

## 注意事项

### 参数类型推导

StringUtil.ParseParamList 自动推导参数类型：

| 输入 | 推导结果 |
|------|----------|
| `123` | number |
| `"hello"` | string（保留引号内的内容） |
| `true` / `false` | boolean |
| `nil` | nil |
| `{1,2,3}` | table（数组） |
| `{a=1,b=2}` | table（字典） |

**常见问题**：
| 问题 | 原因 | 解决方案 |
|------|------|----------|
| 字符串 `"123"` 变数字 123 | 自动推导为 number | 使用 `paramTypes = {"string"}` 强制类型 |
| 布尔值变成字符串 | CSV 存储为文本 | 使用 `paramTypes = {"boolean"}` |
| 表解析失败 | CSV 逗号冲突 | 用引号包裹：`"{a=1,b=2}"` |

### 函数执行时机

```
Refresh() → 执行 > 函数 → 显示内容 → 点击 → 执行 < 函数 → NextID跳转
```

**重要**：
- 条件判断 `$` 类型：仅第一个 `>` 函数的返回值作为跳转ID
- 启动新对话：在 `<` 函数中调用 `DialogueController.Start()` 可安全切换

### 跳转循环保护

系统内置跳转计数器，超过 100 次自动终止并报错，防止无限循环。

### 函数名冲突

后注册的同名函数会覆盖先注册的，日志会显示警告。

## 完整示例

### 对话文件

```lua
return {
    -- 普通对话
    {Sign="#", ID="0", Character="小明", PosAndOp="left&show", Content="你好，欢迎来到这里。", NextID="1"},
    
    -- 条件判断
    {Sign="$", ID="1", Character="", PosAndOp="", Content="", NextID="", Func=">CheckCondition", Params="2;3"},
    
    -- 分支A
    {Sign="#", ID="2", Character="小明", PosAndOp="", Content="你选择了A路线。", NextID="4"},
    
    -- 分支B  
    {Sign="#", ID="3", Character="小明", PosAndOp="", Content="你选择了B路线。", NextID="4"},
    
    -- 选项
    {Sign="%", ID="4", Character="", PosAndOp="", Content="继续探索", NextID="5", Func="", Params=""},
    {Sign="%", ID="5", Character="", PosAndOp="", Content="离开", NextID="END", Func="<StartDialogue", Params="'Dialogue/NextChapter'"},
    
    -- 结束
    {Sign="#", ID="6", Character="小明", PosAndOp="hide", Content="再见！", NextID="END"},
}
```

### 函数实现

```lua
local MyDialogueFunctions = {}
local mt = {__index = require("DialogueFuncRegistry").IDialogueFuncProvider}
setmetatable(MyDialogueFunctions, mt)

MyDialogueFunctions.CheckCondition = {
    name = "CheckCondition",
    paramTypes = {"string", "string"},
    func = function(branchA, branchB)
        local flag = SomeSystem.GetFlag("route")
        return flag and branchA or branchB
    end
}

MyDialogueFunctions.StartDialogue = {
    name = "StartDialogue",
    paramTypes = {"string"},
    func = function(fileName)
        require("DialogueController").Start(fileName)
    end
}

return MyDialogueFunctions
```
