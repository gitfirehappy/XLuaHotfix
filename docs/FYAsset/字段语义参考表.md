# 字段语义参考表

> 已落地代码中所有重要字段的语义定义。
> 防止 Labels/Tags、Address/AssetPath 等易混淆字段被误用。
> 每次新增/修改核心数据结构字段时同步更新本文档。

---

## 一、高危混淆字段对照表

| 对比项 | 字段 A | 字段 B | 区别 |
|--------|--------|--------|------|
| **Labels vs Tags** | `ManifestAssetEntry.Labels` | `ManifestBundleEntry.Tags` | Labels = 资产级逻辑标签，用于运行期查询/过滤（如 "Player", "UI"）。Tags = Bundle 级下载策略标签，用于下载分组（如 "必装", "DLC-1"）。**两者不互通、不自动聚合** |
| **Address vs AssetPath** | `RuntimeAssetEntry.Address` | `CollectedAssetInfo.AssetPath` | Address = 运行期逻辑名，允许重复，是主查询键但不是唯一身份。AssetPath = 项目相对路径（如 "Assets/Textures/icon.png"），仅编辑器诊断用，不参与运行期查询 |
| **EntryId vs AssetGUID** | `ManifestAssetEntry.EntryId` | `CollectedAssetInfo.AssetGUID` | 同一值（Unity GUID）。EntryId 是运行期规范命名，AssetGUID 是构建期命名。跨结构传递时一对一映射 |
| **GroupName vs PackageName** | `CollectedAssetInfo.GroupName` | `CollectedAssetInfo.PackageName` | 层级关系：Package → Group → Collector。PackageName 是顶层包标识，GroupName 是中间层分组 |
| **FileHash vs hash** | `ManifestBundleEntry.FileHash` | `BundleInfo.FileHash` | 已统一为 PascalCase `FileHash` |
| **BundleName vs bundleName** | `ManifestBundleEntry.BundleName` | `BundleInfo.BundleName` | 已统一为 PascalCase `BundleName` |
| **PrimaryType vs BundleType** | `ManifestAssetEntry.PrimaryType` | `ManifestBundleEntry.BundleType` | PrimaryType = 单资产的 Unity 类型名（如 "Texture2D"）。BundleType = Bundle 主导类型（>80% 同类型时取该名，否则 "Mixed"） |
| **BundleEntries vs DeliveryBundles** | `ABManifest.BundleEntries` | `ABManifest.DeliveryBundles` | BundleEntries = 完整运行时 Bundle 表，用于查找和依赖解析。DeliveryBundles = 当前 AB Hotfix 远端包实际交付/下载的 Bundle 列表；Full 为空 |

## 二、核心数据结构字段清单

> Binary 只覆盖运行时加载/下载的 manifest 及其嵌套数据。人类阅读、编辑器工具、构建仓库状态、报告和差异预览数据保持 JSON-only。

### VersionNumber（版本号，全项目统一使用）

> 序列化：`[Serializable]` + `[BinarySerializable]`，同时支持 JSON 和 Binary

| 字段 | 类型 | JSON | Binary | 语义 |
|------|------|:----:|:------:|------|
| `Major` | int | ✓ | [0] | 主版本号 — 不兼容的大版本更新，客户端必须强制更新安装包 |
| `Minor` | int | ✓ | [0] | 次版本号 — 功能性更新，热更可达 |
| `Patch` | int | ✓ | [0] | 修订号 — Bug 修复、资源微调，热更可达 |
| `Build` | int | ✓ | [0] | 构建号 — 每日自增元数据，不参与版本比较 |
| `Channel` | string | ✓ | [0] | 发布渠道 — ""(release), "alpha", "beta", "rc"；参与版本比较：alpha < beta < rc < release |

> 比较规则：Major → Minor → Patch → ChannelRank。Build 不参与。

`VersionDataBase` 是产品版本源，不按 AA / AB 拆分；AA / AB 是构建后端维度，通过 `BackendMode` 写入 PackageIndex、BuildIndexData 和 Build Repository channel。

| `FYAssetSettings` | `BuildOutputRoot` | 构建输出根目录 |
| `FYAssetSettings` | `BuildPackagesFolderName` | 运行期拼接远端包体目录时使用的 Packages 子目录名 |
| `FYAssetSettings` | `VersionDataBasePath` | 产品级共享版本库路径，不按 AA / AB 拆分 |
| `FYAssetSettings` | `BuildIndexJsonPath` | 整包 BuildIndex 项目内副本路径 |
| `FYAssetSettings` | `PushTargets` | Build Repository 发布目标 |
| `FYAssetAASettings` | `HotfixUrl` | AA 运行期热更远端根 URL |
| `FYAssetAASettings` | `HotfixMaxRetryCount` / `HotfixRetryBaseDelaySeconds` | AA 运行期下载重试参数 |
| `FYAssetAASettings` | `BuildPipelineConfigPath` | AA Task 顺序列表配置路径 |
| `FYAssetAASettings` | `ManifestOutputFormat` / `MaxHotfixSizeBytes` | AA manifest 输出格式与热更大小阈值 |
| `FYAssetAASettings` | `LuaScriptsIndexPath` | LuaScriptsIndex 资产路径 |
| `FYAssetABSettings` | `HotfixUrl` | AB 运行期热更远端根 URL |
| `FYAssetABSettings` | `HotfixMaxRetryCount` / `HotfixRetryBaseDelaySeconds` | AB 运行期下载重试参数 |
| `FYAssetABSettings` | `BuildPipelineConfigPath` | AB Task 顺序列表配置路径 |
| `FYAssetABSettings` | `ManifestOutputFormat` / `MaxHotfixSizeBytes` | AB manifest 输出格式与热更大小阈值 |
| `FYAssetABSettings` | `AssetCollectionDataFolder` / `AssetCollectionSettingPath` / `DependencyFilterExtensions` | AB 专属 AssetCollection 数据目录、配置资产路径与依赖过滤扩展 |
| `AssetCollectionSetting` | `ExcludedAssets` | 文件级 Collector 排除项，按 AssetGUID 生效，AssetPath 仅作编辑器展示和审计缓存 |

### PackageIndex（远端包体入口）

| 字段 | 类型 | JSON | 语义 |

| `BackendMode` | string | ✓ | 包体后端类型，值为 `AA` 或 `AB`；运行期必须与当前客户端后端一致 |

### RuntimeAssetEntry（运行期最小资产单元）

> 运行期数据结构，由 ManifestAssetEntry.ToRuntimeEntry() 转换而来。不直接参与 JSON/Binary 序列化。

| 字段 | 类型 | 语义 |
|------|------|------|
| `EntryId` | string | 唯一标识，复用 Unity GUID。缓存键、Handle 归属判定、诊断 ID |
| `Address` | string | 逻辑名，允许重复，不是唯一身份。由 AssetEntry 手动值或自动地址生成器解析。运行期主查询键 |
| `PrimaryType` | string | 资产 Unity 类型名（如 "Texture2D", "GameObject"）。ScriptableObject 用具体子类名 |
| `Labels` | IReadOnlyList\<string\> | 无序唯一标签集。存储保留原始大小写，匹配时大小写不敏感 |
| `SourcePath` | string | 项目相对路径（如 "Assets/Prefabs/Player.prefab"）。仅编辑器诊断，运行期不使用 |
| `Group` | string | 构建组名。仅编辑器诊断，运行期不参与查询或路由 |
| `AutoAddress` | bool | true = 地址由 `AssetCollectionSetting.AddressStyle` 自动生成（重建时可能变化）；false = 手动锁定（永不自动覆盖）。Group 批量 Address 操作只覆盖自动项 |

---

### AssetExclusion（采集排除项）

| 字段 | 类型 | 语义 |
|------|------|------|
| `AssetGUID` | string | 排除项权威键；用于扫描、反向索引和构建收集过滤 |
| `AssetPath` | string | 编辑器展示用缓存路径；资产仍可解析时通过 GUID 刷新 |

`AssetCollectionSetting.ExcludedAssets` 与 `IgnorePatterns` 同属采集过滤配置。删除被 Folder Collector 覆盖的文件会新增排除项；重新添加该资产会删除排除项。

### ManifestBundleEntry（Bundle 元数据）

> 序列化：`[Serializable]` + `[BinarySerializable]`，同时支持 JSON 和 Binary

| 字段 | 类型 | JSON | Binary | 语义 |
|------|------|:----:|:------:|------|
| `BundleName` | string | ✓ | [0] | 唯一 Bundle 标识（如 "characters_assets_all_abc123.bundle"） |
| `FileHash` | string | ✓ | [1] | MD5 内容哈希 — 完整性校验 + 增量更新比对 |
| `FileCRC` | uint | ✓ | [2] | CRC32 校验 — 快速验证 |
| `FileSize` | long | ✓ | [3] | 文件大小（字节）— 下载进度估算 |
| `Encrypted` | bool | ✓ | [4] | 是否加密 |
| `BundleType` | string | ✓ | [5] | 主导类型名或 "Mixed" — 由 Bundle 内资产 PrimaryType 统计推断（>80% 阈值） |
| `Tags` | List\<string\> | ✓ | [6] | Bundle 级下载策略标签（如 "必装", "DLC-1", "background"）。**不是资产 Labels** |
| `DependBundleIndices` | int[] | ✓ | [7] | 直接依赖的 Bundle 索引（指向 ABManifest.BundleEntries） |
| `IncludeAssets` | List\<ManifestAssetEntry\> | — | — | [NonSerialized] 该 Bundle 包含的资源列表（ABManifest.Initialize() 填充） |
| `ReferencedByBundleIndices` | List\<int\> | — | — | [NonSerialized] 反向依赖索引（ABManifest.Initialize() 填充） |

### ManifestAssetEntry（清单资源条目）

> 序列化：`[Serializable]` + `[BinarySerializable]`，同时支持 JSON 和 Binary。运行时字段集与 RuntimeAssetEntry 一致，额外增加 BundleIndex。

| 字段 | 类型 | JSON | Binary | 语义 |
|------|------|:----:|:------:|------|
| `EntryId` | string | ✓ | [0] | 内部唯一身份（复用 Unity GUID）。缓存键、Handle 归属判定、诊断 ID |
| `Address` | string | ✓ | [1] | 逻辑名（允许重复，不是唯一身份）。由 AssetEntry 手动值或自动地址生成器解析。运行期主查询键 |
| `PrimaryType` | string | ✓ | [2] | 资源类型名（如 "Texture2D", "GameObject"）。ScriptableObject 用具体子类名 |
| `Labels` | List\<string\> | ✓ | [3] | 分类标签集合。匹配时大小写不敏感 |
| `SourcePath` | string | ✓ | [4] | 资源在项目中的路径（如 "Assets/Prefabs/Player.prefab"）。仅编辑器诊断 |
| `Group` | string | ✓ | [5] | 构建分组名称。仅编辑器报表与构建语义 |
| `AutoAddress` | bool | ✓ | [6] | true = Address 自动生成（可重建）；false = 手动覆写（锁定）。自动样式来自构建期 `AssetCollectionSetting.AddressStyle` |
| `BundleIndex` | int | ✓ | [7] | 所属 Bundle 在 ABManifest.BundleEntries 中的索引（ABManifest 特有） |

### CollectedAssetInfo（构建中间产物）

| 字段 | 类型 | 语义 |
|------|------|------|
| `AssetPath` | string | 项目相对路径 — 构建期唯一定位 |
| `AssetGUID` | string | Unity GUID — 映射为运行期 EntryId |
| `Address` | string | 运行期地址 — 允许重复，由 AssetEntry 或自动地址生成器解析 |
| `PrimaryType` | string | 资产类型名 — 由 AssetDatabase.GetMainAssetTypeAtPath 获取 |
| `Labels` | List\<string\> | 最终标签 — Group.Labels ∪ AssetEntry.Labels，去重 |
| `GroupName` | string | 所属 Group 名 |
| `PackageName` | string | 所属 Package 名 |
| `BundleName` | string | 逻辑 Bundle 名 — 由 BundlePackingMode + BundleNameBuilder 组装 |
| `Classification` | AssetClassification | 解析后的分类结果 — Role + PayloadKind 两个正交维度 |

| `CollectorType` | ECollectorType | 采集器类型 — 透传自 Collector 配置 |
| `IsInSharedBundle` | bool | 依赖分析标记 — 资产被放入共享 Bundle（$shared 组） |

### ABManifest（清单根结构）

> 序列化：`[Serializable]` + `[BinarySerializable(Magic=0x41424D46, SchemaVersion=2)]`

| 字段 | 类型 | JSON | Binary | 语义 |
|------|------|:----:|:------:|------|
| `PackageName` | string | ✓ | [0] | 包标识（如 "MainPackage"） |
| `PackageVersion` | VersionNumber | ✓ | [1] | 构建版本号 |
| `BuildTimestamp` | string | ✓ | [2] | 构建时间（ISO 8601），调试用 |
| `AssetEntries` | List\<ManifestAssetEntry\> | ✓ | [3] | 所有资产条目 |
| `BundleEntries` | List\<ManifestBundleEntry\> | ✓ | [4] | 所有 Bundle 条目；完整运行时索引，运行时查找和依赖解析始终使用它 |
| `DeliveryBundles` | List\<ManifestBundleEntry\> | ✓ | [5] | 本次远端包实际交付的 Bundle。Full 为空；AB Hotfix 为相对同 Major Full baseline 的 Added/Modified 物理 Bundle |

运行期索引（Initialize 后构建）：
- `_addressIndex`: Address → 资产索引列表（允许重复）
- `_entryIdIndex`: EntryId → 资产索引（唯一）
- `_typeIndex`: PrimaryType → 资产索引列表
- `_labelIndex`: Label(lowercase) → 资产索引列表
- `_bundleNameIndex`: BundleName → Bundle 索引

### Build Repository（构建仓库）

> 序列化：仅 JSON。仓库 HEAD、objects、差异预览和 CLI 输出是人类/工具可读状态文件，不参与 Binary。

RepositoryCommit:
| 字段 | 类型 | JSON | 语义 |
|------|------|:----:|------|
| `Version` | VersionNumber | ✓ | 构建版本 |
| `ChannelKey` | string | ✓ | 仓库 Channel 标识，包含 BuildTarget、可选 Channel、BackendMode |
| `BackendMode` | string | ✓ | 构建后端类型，值为 `AA` 或 `AB` |
| `BuildTarget` | string | ✓ | Unity BuildTarget |
| `PackageName` | string | ✓ | 包体名称 |
| `CreatedAtUtc` | string | ✓ | Commit 创建时间，UTC ISO-8601 字符串 |
| `GitCommitHash` | string | ✓ | 当前 git HEAD 的 commit hash（git 不可用时为空） |
| `IsDirty` | bool | ✓ | 工作区是否有未提交的变更 |
| `PackageRootDir` | string | ✓ | 最终包体输出目录，Push 时用于定位产物文件 |
| `BuildType` | string | ✓ | 构建类型，值为 `Full` 或 `Hotfix`；AB Hotfix 用它查找同 Major Full baseline |
| `ParentVersion` | string | ✓ | 当前提交的父提交版本；首个提交为空 |
| `CommitDelta` | ArtifactDelta | ✓ | 当前提交相对父提交的固定差异；首个提交为全量 Added |
| `Artifacts` | List\<ArtifactDigest\> | ✓ | 本次构建写入 HEAD 的产物指纹列表 |

RepositoryHeadState:
| 字段 | 类型 | 语义 |
|------|------|------|
| `HeadVersion` | string | 当前 HEAD 指向的 Version，object 路径由目录布局推导 |

ArtifactDigest:
| 字段 | 类型 | JSON | 语义 |
|------|------|:----:|------|
| `Name` | string | ✓ | 产物身份；AA 使用 Asset GUID，AB 使用 BundleName |
| `Hash` | string | ✓ | 内容 Hash，当前使用 MD5 字符串 |
| `Size` | long | ✓ | 产物大小，单位为 byte |
| `CRC` | uint | ✓ | CRC32 快速校验值 |

ArtifactDelta:
> 序列化：`[Serializable]`，仅 JSON（差异预览/CLI/仓库工具输出，不参与 Binary）

| 字段 | 类型 | JSON | 语义 |
|------|------|:----:|------|
| `Added` | List\<ArtifactDigest\> | ✓ | 目标侧存在、基准侧不存在的产物 |
| `Modified` | List\<ArtifactDigest\> | ✓ | 两侧 Name 相同但 Hash 不同的产物 |
| `Removed` | List\<string\> | ✓ | 基准侧存在、目标侧不存在的产物 Name |
| `IsEmpty` | bool (computed) | — | 没有任何新增、修改或删除 |

## 三、枚举语义

### ECollectorType（采集器类型）

| 值 | 语义 |
|----|------|
| `Main` (0) | 可寻址入口资产，运行时通过 Address 加载 |
| `Static` (1) | 内部打包资产，不对外暴露 Address |
| `Depend` (2) | 仅作为依赖项打包，不直接加载 |
| `Implicit` (3) | 由依赖分析自动发现的隐式依赖资产 |

### EPayloadKind（载荷类型）

| 值 | 语义 |
|----|------|
| `Serialized` (0) | 标准序列化资产（Prefab/Texture/Material），打入 AssetBundle |
| `RawFile` (1) | 原始文件，直接拷贝，不打入 AssetBundle |
| `Scene` (2) | 场景文件，Unity 要求独立打包为 Scene Bundle |

### EAssetRole（资产语义角色）

| 值 | 语义 |
|----|------|
| `Main` (0) | 来自 Main 采集器的可寻址入口资产 |
| `Static` (1) | 来自 Static 采集器的内部打包资产 |
| `Depend` (2) | 来自 Depend 采集器的显式声明依赖资产 |
| `ImplicitDependency` (3) | 由依赖分析发现的隐式依赖资产 |

### EForcePayloadKind（强制载荷覆盖）

| 值 | 语义 |
|----|------|

| `RawFile` (2) | 强制视为原始文件 |
| `Scene` (3) | 强制视为场景文件 |

## 五、命名规范

| 规则 | 说明 |
|------|------|
| 全项目统一用 PascalCase | `EntryId`, `FileHash`, `BundleName`, `PackageName`, `Version`, `TotalSize`, `FileSize` |
| 同语义跨结构必须同名 | `PrimaryType` 在 RuntimeAssetEntry / ManifestAssetEntry / CollectedAssetInfo 中一致 |
| Labels 永远是资产级 | 不要在 Bundle 结构上使用 Labels 命名 |
| Tags 永远是 Bundle 级 | 不要在资产结构上使用 Tags 命名 |
| Hash 字段统一为 FileHash | 新代码中不再使用 `hash`、`Hash`、`ContentHash` 等变体 |
| Address 不要求唯一 | 同名 Address 允许存在；解析依赖 `Address + PrimaryType + Labels`，完全无法区分时才阻断 |

## 六、BundlePackingMode（Group 打包模式）

| 值 | 语义 |
|----|------|
| `PackTogether` (0) | Group 下资产打入一个 Bundle：`{package}_{group}_all` |
| `PackSeparately` (1) | 每个资产一个 Bundle：`{package}_{group}_asset_{normalizedAddress}~{shortGuid8}` |
| `PackTogetherByLabel` (2) | 按最终 Labels 分组：`{package}_{group}_labels_{labelA}~{labelB}`；无标签使用 `$unlabeled` |
