# FYAsset 资源管理总览

> **关联代码** | [FYAsset/Scripts](../../Assets/FYAsset/Scripts/)

FYAsset 包含 Addressables（AA）与自研 AssetBundle（AB）两条具体实现。两者复用构建编排、版本、基线、发布与热更流程，但不共用资源索引或加载器。本文提供职责导航；详细调用链与全部 C# 文件职责见 [HTML 建模文档](./fyasset-modeling.html)。

## 所有权

| 目录 | 负责 | 不负责 |
|---|---|---|
| `AA/` | Addressables 构建、catalog、AAManifest、AA 资源加载与热更后端 | AB 采集、Bundle 加载 |
| `AB/` | Collection、依赖分析、ABManifest、Bundle 构建与加载、AB PlayMode | Addressables Group 修改 |
| `Shared/` | 版本、线性 Task 机制、交付基线、发布机制、热更编排与公共数据 | 宿主选择 AA/AB |
| `Compat/` | 宿主后端选择、兼容门面、Lua 索引构建接入、Cloudflare 发布接入 | 替代 AA/AB 的具体实现 |
| `Tests/` | 构建测试、E2E、测试服务和验证入口 | 正式业务运行入口 |

`Assets/Tools/Scripts/Serialization` 是通用序列化工具。FYAsset 的类型注册与生成代码归 `Compat/Serialization`，不是工具内置类型。目录边界不等于已经拆分成独立程序集或可单独导出安装的包。

## 核心流程

| 流程 | 输入与结果 | 边界 |
|---|---|---|
| AB Collection | Project Scan 得到只读预览，确认后进入 Curate 候选配置；Save 验证并持久化 | Labels 随候选配置 Save/Cancel；不再有独立立即保存页面 |
| AB 构建 | 采集、依赖、Bundle 构建、Manifest 校验、Diff、交付 | Full/Hotfix/Standalone 各有输出语义 |
| AA 构建 | Addressables source Diff、Hotfix Group 移动、BuildPlayerContent、输出整理 | Labels 在 Addressables 原生编辑器维护，Group 恢复是独立操作 |
| 基线与交付 | `BuildBaselineStore` 保存 `Latest` 与 `LatestFull` | 不保存 object/HEAD 历史；AB 暂存交付与 AA 现有路径不同 |
| 发布 | `BuildPublisher` 从已交付基线的包目录读取，发布到目标并更新索引 | 不重新构建，不自动修改运行时 HotfixUrl |
| 热更 | BuildIndex、本地/远端 PackageIndex、Manifest 驱动检查、下载、校验与激活 | 不完整目标不能作为成功初始化结果；具体失败分支见专题 |
| 运行时 | AA 通过 Addressables，AB 通过索引、Backend、BundleLoader | 普通资源释放与 AB Handle 释放不能混用 |

构建与发布目录职责不同：默认 `HotfixOutput` 保存构建交付包；`HotfixPublish` 保存发布镜像或部署暂存数据。文件复制不意味着职责重复。运行时使用单独配置的 URL，不依赖这两个本地目录名称。

## AA 与 AB

| 维度 | AA | AB |
|---|---|---|
| 定位 | Addressables catalog | ABManifest 索引 |
| Manifest | Bundle 校验和资产查询数据，catalog 负责实际定位 | 资产、完整 Bundle 集合及依赖映射 |
| 加载 | `AAPackageManager` / Addressables | `ABPackageManager` / `ABPackageBackend` / `ABBundleLoader` |
| 生命周期 | Addressables Handle tickets | Asset/Bundle 引用计数与 `AssetHandle<T>` 注册表 |
| 构建入口 | `AABuildProjectManager` | `ABBuildProjectManager` |
| 配置 | `FYAssetAASettings` | `FYAssetABSettings`，含 PlayMode |

Compat 的 `FYAssetBackendSettings` 提供宿主选择；具体 AA/AB 构建窗口不以宿主选择禁用另一侧。运行时不应在已绑定资源所有权后随意切换后端。

## 事实边界

本文按源码描述，不以历史测试通过推导当前所有流程正确。AB 的交付补偿和发布事务都会遇到补偿本身失败的情况，不提供跨文件、跨网络的不可失败保证。真实 Unity 构建、Player、Android StreamingAssets 与远端部署需要分别验证；具体未决验收保留在 requirements。
