# Mistakes Index

Record only verified mistakes or confirmed troubleshooting outcomes. Each entry uses:

`Symptom -> Root cause -> Fix -> Prevention`

Optional `Scope` and `Verification` metadata may be added when they improve retrieval. Do not record speculation,
ordinary design decisions, plan status, or execution diaries.

## Files

- `implementation.md` - runtime, data-model, API, and shared implementation pitfalls.
- `editor.md` - editor UI, collection workflow, and editor-state pitfalls.
- `build-publish.md` - build pipeline, artifact, repository, and publication pitfalls.
- `process.md` - progress, review, and repository-operation pitfalls.

The index is a catalog only. It does not summarize current architecture or provide a project status timeline.
