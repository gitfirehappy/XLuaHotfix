# Dependencies Knowledge Index

This domain contains two distinct kinds of knowledge:

- `integration/`: direct project dependency integration notes
- `reference/`: external frameworks, engine internals, and research references

## Subdomains

| Subdomain | Path | Description |
|-----------|------|-------------|
| Integration | [integration/](integration/) | Notes for libraries and packages directly integrated into XLuaHotfix |
| Reference | [reference/](reference/) | External frameworks, protocols, engine internals, and papers used as design references |
