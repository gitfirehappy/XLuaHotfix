# 命令行构建指南

> **关联代码** \| `Assets/FYAsset/Scripts/Build/` · `Assets/FYAsset/Scripts/Build/Collector/Editor/` · `CommandLine/`

## 概述

项目支持在 Unity Editor 外部通过命令行执行资源构建，适用于 CI/CD 集成和批量出包场景。正式构建入口为 `BuildCommandLine.Build`，当前支持 `full` 和 `hotfix` 两种 `-buildType`。

正式构建后端由 `FYAssetSettings.Instance.UseABBackend` 决定；`BuildCommandLine.Build` 不通过命令行参数覆盖 AA/AB 后端。Repository CLI 的 `-backend` 只用于仓库通道选择。

## 构建流程全景

```
Collector 配置 → 收集资产 → 分类 → 打包 → 生成 Bundle → 构建清单 → 输出
                                                              ↓
                                                     BuildIndexData
                                                     ABManifest
                                                     Bundle 文件
```

每次构建产出：
- **Bundle 文件**：实际的 AssetBundle 资源包
- **ABManifest**：Bundle 清单（.bin + .json），记录 Bundle 名、Hash、大小、依赖关系
- **PackageIndex**：远端最新包体指针，记录最新包名、版本和后端模式；访问位置由发布根 + `BuildPackagesFolderName` + 包名推导
- **BuildIndexData**：Full Build 本地启动索引，记录版本、包 GUID 和后端模式

## 快速开始

### 1. 配置 Unity 路径

编辑 `CommandLine/build.config`：

```ini
UnityPath="~\2022.3.6f1c1\Editor\Unity.exe"
```

### 2. 执行构建

推荐在 CI 中直接调用 `BuildCommandLine.Build`。`CommandLine/build.bat` 仍可作为本地包装脚本使用，但正式入口只识别 `full` / `hotfix`：

```
========================================
       Unity Build Tool
========================================

[1] Hotfix Build (Patch+1)
[2] Full Package Build (Major+1)

Select build mode (1/2):
```

构建日志输出到 `HotfixOutput/build.log`。

## 构建模式

| 模式 | 版本变化 | 产出 | 适用场景 |
|------|---------|------|---------|
| Hotfix | Patch+1 | 增量 Bundle + 热更清单 | 修 bug、更新单个资源 |
| Full Package | Major+1 | 全量 Bundle + 完整清单 | 大版本发布、基线刷新 |

旧的 `ConfirmRelease` 自动固化入口不属于当前正式命令行构建入口；Repository commit / diff / push 由构建仓库链路负责。

## CI/CD 集成

在 CI 环境中直接调用 Unity 命令行：

```bash
Unity.exe -batchmode -quit \
    -projectPath "E:/unity/project/XLuaHotfix" \
    -executeMethod BuildCommandLine.Build \
    -buildType hotfix \
    -logFile "HotfixOutput/build.log"
```

支持的 `-buildType` 参数：`hotfix`、`full`。

## 退出码

| 退出码 | 含义 |
|--------|------|
| 0 | 构建成功 |
| 1 | 构建失败（详见日志） |

## 前置条件与注意事项

- **必须关闭 Unity Editor**：脚本启动前自动检测，Unity 运行中会提示并退出
- **Collector 配置必须就绪**：确保 `AssetCollectionSetting` 资产已配置，否则收集阶段无产出
- **后端选择来自 Settings**：切换 AA/AB 请修改 `FYAssetSettings.UseABBackend`，不要通过构建命令行覆盖
- **构建完成后检查日志**：`HotfixOutput/build.log` 包含完整构建记录和错误详情
- **批量构建**：可通过脚本循环调用不同 `-buildType` 实现多模式连续构建
