## 对话系统语义定义
- **Sign**：标识符（对话/选项/条件判断）
    - 对话 ：`#`
    - 选项 ：`%`
    - 条件判断 ：`$`
    - 若为空，则默认为# 普通对话
- **ID**：每条语句唯一标识，起始ID建议为0，也支持其他起始 ID
- **Character**：说话的人
    - 需要同时出现或不同位置操作时会用 ; 隔开但只将第一个作为说话的人
      - 例 **小明;小红** 说话人为小明，但对小红有额外操作
    - 允许空值，表示旁白或特指说话人
        - 例 **p1&p2;p1;p2** p1&p2同时说话，对二者有操作
        - 例 **;p1;p2** 无说话人，旁白，但对二者有操作
    - `角色_xxx` 可用于单角色匹配多CharacterConfig，UI上只显示角色名称
- **PosAndOp**：说话的人出现的位置或者对角色快捷操作(如隐藏出现等)
    - 对多角色操作时会用 `;` 隔开
    - 单个角色多操作用 `&` 隔开
      - 例 **left&diff1;hide** 意为角色1在左侧显示并且图片差分1，角色2隐藏
    - 允许空值，表示无位置或无操作，角色维持原状态
    - 位置可通过Panel面板自定义，名称 - 坐标标记物体
      - 固定快捷操作包括：
        - `show` ：显示角色
        - `hide` ：隐藏角色
        - `diffX` ：切换角色图片差分，X为差分编号
- **Content**：对话内容
  - 允许空值，通常用于条件判断，仅执行函数进行条件判断而不显示文本
  - 使用 `\n` 进行换行
- **NextID**：跳转
    - 单个数字ID ：跳转到普通语句
    - 多个数字ID,分号间隔,跳转到选项
      - 例 **3;4;5** 
    - `END` ：结束这段对话
    - $ 条件判断没有跳转ID，通过>函数进行条件判断，返回值为**NextID**，仅第一个函数作为参考
- **Func**：选择后执行函数
    - C#版本：可使用的函数需打上标签`[DialogueFunc]`,所处类需继承接口`IDialogueFuncProvider`
    - Lua版本：可使用函数需设置元表`local mt = {__index = require("DialogueFuncRegistry").IDialogueFuncProvider}
  setmetatable(DemoDialogueFunctions, mt)` 且需要以表的方式编写函数，附带函数名和参数类型规定（可选），具体参考示例
    - `>函数名` : 在语句出现时执行
    - `<函数名` : 在点击后执行
      - 通常用于选项，且可以在END语句中开启下一段对话使用，但必须放在最后一个函数位置，最好避免其他函数执行
    - 若有多个函数，则用 `;` 隔开
      - 例 ：>func1;<func2
- **Params**：函数入参
    - 单个函数多个入参用 `&` 隔开
    - 不同函数的入参用 `;` 隔开
    - 支持表类型，最好使用引号包含{}，否则可能影响csv对逗号的解析：
      - 列表（List）：`{1, 2, 'a', true}`
      - 字典（Dictionary）：`{hp=10, name='boss', flag=false}`
      - 可嵌套：`{drop={1,2,'gem'}, info={id=1}}`
