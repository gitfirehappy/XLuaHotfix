# tools-docs-hash-20260420

## 背景

当前 `docs/Tools/序列化工具.md` 更像实现说明，缺少面向使用者的入口、适用场景和常见注意事项，不够“说人话”。

同时 `HashGenerator` 仍位于 FYAsset 模块目录下，但其职责已经偏通用工具；哈希相关描述也混入了热更包的业务语义，不利于后续复用和理解。

## 目标

1. 优化序列化工具文档，只描述当前已经实现的能力，补足使用指南、原理说明和架构设计介绍。
2. 在不改变现有功能行为的前提下，将 `HashGenerator` 迁移到 `Assets/Tools` 通用工具目录。
3. 优化哈希工具和调用处说明，使通用工具只保留通用语义，业务特例回到业务层。

## 约束

- 不修改现有功能行为，只允许修改描述、变量名、注释、目录归类，以及在必要时调整更清晰的方法名。
- 文档只写现有实现，不写未来规划和未落地方案。
