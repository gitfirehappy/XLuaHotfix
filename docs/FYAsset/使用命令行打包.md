# 命令行构建指南

## 快速开始

### 1. 配置 Unity 路径

首次使用前，编辑 `CommandLine/build.config` 文件，设置你的 Unity 安装路径：

```ini
UnityPath="E:\unity\AllEditor\2022.3.6f1c1\Editor\Unity.exe"
```

### 2. 执行构建

双击运行 `CommandLine/build.bat`，根据菜单选择构建模式：

```
========================================
       Unity Build Tool
========================================

[1] Hotfix Build (Patch+1)
[2] Full Package Build (Major+1)
[3] Hotfix + ConfirmRelease

Select build mode (1/2/3): 
```

构建日志自动输出到 `HotfixOutput/build.log`。

## 注意事项

- **必须关闭 Unity Editor**：脚本会自动检测，如果 Unity 正在运行会提示并退出
- **构建完成后**：窗口会显示成功/失败状态，按任意键关闭

## 构建模式说明

| 模式 | 说明 |
|------|------|
| Hotfix | 构建热更包，小版本号 Patch+1 |
| Full | 构建完整包，大版本号 Major+1 |
| Hotfix + ConfirmRelease | 构建热更包并自动执行 ConfirmRelease |

## 退出码

| 退出码 | 含义 |
|--------|------|
| 0 | 构建成功 |
| 1 | 构建失败 |

## CI/CD 集成

在 CI 环境中可直接调用 Unity 命令行：

```bash
Unity.exe -batchmode -quit \
    -projectPath "E:/unity/project/XLuaHotfix" \
    -executeMethod BuildCommandLine.Build \
    -buildType hotfix \
    -logFile "HotfixOutput/build.log"
```
