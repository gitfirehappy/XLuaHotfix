# Knowledge Index

`context/` stores stable, verified, reusable knowledge for future work. It is not a current-status board, plan
queue, TODO list, or document archive.

## Categories

- `conventions/` - stable project-specific engineering rules.
- `mistakes/` - verified mistakes and confirmed troubleshooting outcomes.
- `reference/` - external-source notes and their bounded conclusions.

Source and tests define current behavior. Current architecture, implementation explanations, tool instructions, and
historical decisions belong in `docs/` or the relevant `requirements/` record.

## Rules

- Add only verified, reusable knowledge.
- Keep each entry focused on one subject.
- Do not mix external references with project rules or current implementation facts.
- Keep indexes as navigation and boundary descriptions, not as a second status or architecture document.
