# 配置数据转换工具

> **关联代码** \| `Assets/Tools/Scripts/ConfigConvertTool/`

## 概述

配置文件格式批量转换工具，支持 CSV / JSON / XML 三种输入格式和 Lua / JSON / XML 三种输出格式。通过统一的中间数据模型（`ConfigData`）解耦 Reader 和 Writer，新增格式只需实现 Reader 或 Writer 接口。

## 架构设计

```
输入文件 → Reader 解析 → ConfigData 中间态 → Writer 输出 → 输出文件

Reader: CsvReader / JsonReader / XmlReader
Writer: LuaWriter  / JsonWriter / XmlWriter
```

### ConfigData 中间态

所有 Reader 将输入统一为两种中间表示：

- **Array 模式**：表格数据（Columns + Rows），适用于 CSV 和扁平 JSON
- **KeyValue 模式**：树形节点（RootNode → Children），适用于 XML 和嵌套 JSON

### 类型推导

Reader 自动根据内容判断字段类型，数字统一按 `double` 处理。如需精确类型控制，在 C# 层调用时显式指定。

## 使用方式

### 1. 打开工具窗口

菜单：`Tools → Config Converter`

### 2. 创建通道配置

右键 Project 窗口：`Create → Config → ConfigConvertChannel`

配置项：

| 字段 | 说明 |
|------|------|
| `inputFolder` | 输入文件目录 |
| `outputFolder` | 输出文件目录 |
| `inputFormat` | 输入格式（CSV / JSON / XML） |
| `outputFormat` | 输出格式（Lua / JSON / XML） |

### 3. 执行转换

三种模式：

| 模式 | 作用 |
|------|------|
| 转换单个文件 | 指定文件路径 + 通道配置 |
| 转换单个通道 | 按通道配置转换整个目录 |
| 转换所有通道 | 按总配置文件批量执行多个通道 |

### 代码调用

```csharp
// 转换单个文件
ConfigConverter.Instance.ConvertFile(filePath, channel);

// 转换整个通道
ConfigConverter.Instance.Convert(channel);

// 转换所有通道
ConfigConverter.Instance.ConvertAll(settings);
```

## 示例：XML 转 Lua

1. 创建 `ConfigConvertChannel`，设置：
   - `inputFolder`: `Assets/Config/Xml`
   - `outputFolder`: `Assets/Config/Lua`
   - `inputFormat`: `Xml`
   - `outputFormat`: `Lua`

2. 在工具窗口选择该通道，点击"转换单个通道"

## 格式特性与常见问题

### XML 特有行为

| 行为 | 说明 |
|------|------|
| 根节点保留 | XML 根节点作为 TreeNode.Name，输出时可能成为表键 |
| 属性前缀 `@` | XML 属性在输出中保留 `@` 前缀以区分子元素 |
| 同名节点合并 | 同名子节点超过一个时，自动识别为数组 |

### 类型推导问题

| 问题 | 原因 | 解决方案 |
|------|------|---------|
| `"123"` 变数字 123 | 自动推导为 number | C# 层显式指定类型 |
| 对象变数组 | 多个同名子节点触发数组识别 | 调整 XML 结构 |
| 根节点丢失 | 被当作表键消耗 | 检查输出结构 |

---

## 注意事项

- 转换后检查输出文件结构是否符合预期
- 复杂嵌套结构建议先用小文件测试
- XML 属性和子元素通过 `@` 前缀区分
- 批量转换前确认 outputFolder 路径正确，避免覆盖已有文件
