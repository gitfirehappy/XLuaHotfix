# 配置数据转换工具

## 功能

配置文件格式转换，支持批量处理。

**输入格式**：CSV、JSON、XML
**输出格式**：Lua、JSON、XML

## 使用方式

### 1. 打开工具窗口

菜单栏：`Tools > Config Converter`

### 2. 创建通道配置

右键 Project 窗口：`Create > Config > ConfigConvertChannel`

配置项：
- `inputFolder`：输入目录
- `outputFolder`：输出目录
- `inputFormat`：输入格式
- `outputFormat`：输出格式

### 3. 执行转换

三种模式：

| 模式 | 说明 |
|------|------|
| 转换单个文件 | 指定文件路径 + 通道配置 |
| 转换单个通道 | 通道配置（转换整个目录） |
| 转换所有通道 | 总配置文件（多通道批量） |

## 示例：XML 转 Lua

1. 创建 `ConfigConvertChannel`，设置：
   - inputFolder: `Assets/Config/Xml`
   - outputFolder: `Assets/Config/Lua`
   - inputFormat: `Xml`
   - outputFormat: `Lua`

2. 在工具窗口选择该通道，点击"转换单个通道"

## 注意事项

### 转换原理

```
输入文件 → Reader解析 → ConfigData中间态 → Writer输出
```

**中间态结构**：
- **Array 模式**：表格数据（Columns + Rows）
- **KeyValue 模式**：树形节点（RootNode → Children）

**类型推导**：Reader 根据内容自动判断类型，数字统一用 double 处理。

### 常见问题

| 问题 | 原因 |
|------|------|
| 根节点被保留/丢失 | XML 根节点作为 TreeNode.Name，输出时可能成为表键 |
| 字符串变数字 | `"123"` 被 SimpleXML 推导为数字类型 |
| 对象变数组 | 同名子节点超过一个时，自动识别为数组 |
| 属性前缀 `@` | XML 属性在输出中保留 `@` 前缀以区分元素 |

### 建议

- 转换后检查输出文件结构是否符合预期
- 复杂嵌套结构建议先用小文件测试
- XML 属性和子元素在输出中通过 `@` 前缀区分

## 代码调用

```csharp
// 转换单个文件
ConfigConverter.Instance.ConvertFile(filePath, channel);

// 转换整个通道
ConfigConverter.Instance.Convert(channel);

// 转换所有通道
ConfigConverter.Instance.ConvertAll(settings);
```
