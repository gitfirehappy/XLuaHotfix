# 二进制序列化

本系统把 C# 对象直接序列化成紧凑的二进制字节流，主要用于 AB 包 Manifest 等运行时需要快速读写的数据。

---

## 整体结构

```
BinaryCodec          ← 对外唯一入口，负责注册类型、序列化/反序列化
  └─ BinaryHeader    ← 每份二进制数据开头的 8 字节头（Magic + SchemaVersion + Flags）
  └─ *_BinarySerializer (生成代码)  ← 每种类型的具体读写逻辑
       └─ BinaryReflectionSerializer  ← 底层按 [BinaryField] 递归读写字段
```

---

## 给数据类打标记

```csharp
[BinarySerializable]          // 告诉生成器要处理这个类
public class MyData
{
    [BinaryField(0)] public string Name;
    [BinaryField(1)] public int Count;
    [BinaryField(2)] public List<string> Tags;  // 支持 List<T>、T[]
    [BinaryField(3)] public MyData Child;       // 支持嵌套，null 也可以
}
```

**注意：`[BinaryField]` 的 Order 决定字段写入顺序，一旦有数据落地就不能随意改变顺序或删除字段，否则老数据读出来会乱。**

---

## 生成序列化代码

菜单：**XLua → Serialization → Generate Binary Serializers**

生成结果在 `Assets/AboutXLua/Scripts/Utility/Serialization/Generated/`，文件名格式为 `{TypeName}_BinarySerializer.cs`。

类型或字段有变动后重新执行一次即可，生成器会自动检测哈希变化并覆盖旧文件。

---

## 注册类型

在初始化时把生成的读写方法注册到 `BinaryCodec`：

```csharp
var codec = new BinaryCodec();

codec.Register<MyData>(
    magic: 0xABCD1234u,                    // 唯一标识这种数据的魔数，不同类型不能重复
    writeWithHeader: (writer, obj) => MyData_BinarySerializer.WriteWithHeader(writer, obj),
    readWithHeader: reader => (MyData)MyData_BinarySerializer.ReadWithHeader(reader)
);
```

Magic 建议在常量文件里集中管理，避免冲突。

---

## 序列化 / 反序列化

```csharp
// 序列化
byte[] bytes = codec.Serialize(myObj);

// 反序列化
MyData result = codec.Deserialize<MyData>(bytes);
```

- `Serialize` 传入 null 返回空字节数组
- `Deserialize` 遇到数据头不合法时返回 `default`，Magic 不匹配时抛 `InvalidDataException`

---

## null 的处理

写入侧会把 null 编码进二进制（引用类型写 hasValue=0，列表/数组写 count=-1），读取侧对称地还原为 null。

| 情况 | 写入 | 读出 |
|---|---|---|
| 引用类型字段为 null | hasValue = 0 | null |
| string 为 null | hasValue = 0 | null |
| List / Array 为 null | count = -1 | null |

---

## 版本兼容

每份数据头里有 `SchemaVersion`，读取时若文件版本比当前代码版本新则报错，旧版文件可以被新代码读取（向前兼容）。

新增字段时需要同时升级 SchemaVersion 并在读取端做好缺省值处理。

---

## 错误情况速查

| 异常 | 原因 |
|---|---|
| `InvalidOperationException: 未注册二进制类型` | 调用 `Serialize` 前忘了 `Register` |
| `InvalidDataException: Magic 不匹配` | 字节数据不属于这种类型，或文件损坏 |
| `InvalidDataException: SchemaVersion too new` | 用旧代码读了新版本数据 |
| `NotSupportedException: 不支持的二进制字段类型` | 字段类型不在支持列表里（目前支持：基础值类型、string、enum、List\<T\>、T[]、嵌套 [BinarySerializable] 类型） |
