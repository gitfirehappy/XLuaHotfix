# 文档目录

本目录存放面向开发者的项目文档，按模块组织。

## 目录结构

- `FYAsset/` —— 自研 AB 资源管理系统（架构设计、使用指南、重构记录）
- `Tools/` —— 通用工具（序列化、配置转换等，与项目业务无关）
- `Dialogue/` —— 对话系统使用说明
- `XLuaFramework/` —— XLua 框架适配（待补充）

## 与 context/ 的区别

| 目录 | 读者 | 语言 | 内容 |
|---|---|---|---|
| `docs/` | 人 | 中文 | 设计文档、使用说明、流程说明 |
| `context/` | AI | English | 已验证的技术知识、约束、经验 |
